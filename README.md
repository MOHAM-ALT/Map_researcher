# Map_researcher 0.5V - أداة لجمع وتحليل بيانات الفنادق

## مقدمة

أداة Map_researcher هي نظام متكامل لجمع وتحليل بيانات المنشآت الفندقية من مصادر متعددة مثل خرائط Google وOpenStreetMap ومنصات الحجز المختلفة. تم تصميم الأداة خصيصاً للكشف عن المنشآت الفندقية الرسمية وغير الرسمية، مما يساعد في تحسين الامتثال للأنظمة في قطاع الفنادق.

في الإصدار 0.5، تمت إضافة ميزات متقدمة للاستكشاف والبحث باستخدام تقنيات التعلم الآلي وتحليل البيانات للعثور على المنشآت الفندقية التي قد لا تكون مصنفة رسمياً.

## كيفية البدء

### متطلبات النظام
- Python 3.6+
- إنترنت (للبحث عن الفنادق)
- مساحة تخزين كافية للبيانات
- ذاكرة كافية لعمليات التحليل والتعلم الآلي

### خطوات التثبيت

1. قم بتشغيل `install.bat` لتثبيت الأداة:
   ```
   install.bat
   ```

2. اختر طريقة التثبيت المناسبة:
   - **البيئة الافتراضية** (موصى بها): تثبيت في بيئة معزولة
   - **التثبيت العالمي**: تثبيت على نظام Python الرئيسي
   - **تخطي التثبيت**: استخدام بدائل للمكتبات المفقودة

3. بعد اكتمال التثبيت، قم بإضافة مفتاح API الخاص بك لخرائط Google في ملف `config\config.json`.

4. يمكنك تشغيل البرنامج باستخدام `run.bat`:
   ```
   run.bat
   ```

### حل المشاكل

إذا واجهتك مشاكل في التثبيت أو التشغيل:

1. **مشاكل مع المكتبات**: البرنامج يتضمن آلية "fallbacks" للعمل حتى عند عدم وجود بعض المكتبات. يمكنك فحص ملف `logs\hotel_researcher.log` لمعرفة المكتبات المفقودة.

2. **مشاكل في Python**: تأكد من إصدار Python (3.6+) وأنه مضاف إلى متغير PATH.

3. **مشاكل في Selenium**: للبحث المتقدم في خرائط Google، تحتاج إلى تثبيت Selenium وWebDriver المناسب (Chrome أو Firefox).

4. **تثبيت المكتبات يدويًا**: يمكنك تثبيت المكتبات يدويًا باستخدام:
   ```
   pip install -r requirements.txt
   ```

## تكوين البرنامج

يمكنك تكوين البرنامج عن طريق تعديل ملف `config\config.json` الذي يحتوي على الإعدادات التالية:

```json
{
  "api_keys": {
    "google_maps": "YOUR_API_KEY_HERE",
    "openstreetmap": ""
  },
  "search_settings": {
    "default_radius": 5000,
    "max_results": 200,
    "min_reviews_count": 3,
    "default_search_language": "ar"
  },
  "machine_learning": {
    "model_path": "models/hotel_classifier.pkl",
    "confidence_threshold": 0.6
  },
  "database": {
    "type": "sqlite",
    "path": "data/hotels.db"
  },
  "ui_settings": {
    "use_rich_output": true,
    "default_export_format": "excel"
  },
  "discovery_modules": {
    "google_maps": true,
    "booking_platforms": true,
    "smart_location": true,
    "reviews_analysis": true,
    "pattern_discovery": true
  }
}
```

### شرح إعدادات التكوين

- **api_keys**: مفاتيح API للخدمات المختلفة
  - **google_maps**: مفتاح API لخرائط Google
  - **openstreetmap**: مفتاح API لـ OpenStreetMap (غير مطلوب عادة)

- **search_settings**: إعدادات البحث
  - **default_radius**: نصف القطر الافتراضي للبحث (بالأمتار)
  - **max_results**: الحد الأقصى لعدد النتائج
  - **min_reviews_count**: الحد الأدنى لعدد التعليقات للتحليل
  - **default_search_language**: لغة البحث الافتراضية

- **machine_learning**: إعدادات التعلم الآلي
  - **model_path**: مسار نموذج التعلم الآلي
  - **confidence_threshold**: حد الثقة لتصنيف الفنادق

- **database**: إعدادات قاعدة البيانات
  - **type**: نوع قاعدة البيانات (sqlite, postgresql, etc.)
  - **path**: مسار قاعدة البيانات

- **ui_settings**: إعدادات واجهة المستخدم
  - **use_rich_output**: استخدام مخرجات نصية غنية
  - **default_export_format**: تنسيق التصدير الافتراضي

- **discovery_modules**: تفعيل/تعطيل وحدات الاكتشاف
  - **google_maps**: تفعيل البحث في خرائط Google
  - **booking_platforms**: تفعيل البحث في منصات الحجز
  - **smart_location**: تفعيل التحليل الذكي للمواقع
  - **reviews_analysis**: تفعيل تحليل التعليقات
  - **pattern_discovery**: تفعيل اكتشاف الأنماط

## الميزات الجديدة في الإصدار 0.5

1. **استكشاف متقدم عبر خرائط Google**: تحليل متعمق لبيانات خرائط Google للعثور على الفنادق المخفية.
2. **تحليل التعليقات والمراجعات**: استخدام تقنيات معالجة اللغة الطبيعية لتحليل التعليقات واكتشاف المنشآت الفندقية غير المصنفة.
3. **التحليل الجغرافي الذكي**: اكتشاف المنشآت الفندقية من خلال تحليل المناطق التجارية والسياحية.
4. **التعلم الآلي للتصنيف**: استخدام نماذج التعلم الآلي لتصنيف المنشآت المكتشفة.
5. **اكتشاف الأنماط والمجموعات**: تحليل العلاقات بين المنشآت الفندقية لاكتشاف المجموعات والأنماط.

## ملاحظات هامة

- **مفتاح Google Places API**: للاستفادة الكاملة من وظائف البحث، يجب عليك الحصول على مفتاح Google Places API وإضافته إلى ملف التكوين.
- **دعم PostgreSQL**: إذا كنت ترغب في استخدام PostgreSQL، تأكد من تثبيت psycopg2 بنجاح.
- **متطلبات Selenium**: تحتاج إلى تثبيت Selenium وWebDriver المناسب (Chrome أو Firefox) لاستخدام وظائف البحث المتقدم في خرائط Google.
- **الخرائط**: تتطلب ميزة إنشاء الخرائط مكتبة folium.
- **تحليل التعليقات**: تتطلب ميزة تحليل التعليقات مكتبة NLTK مع تنزيل بيانات إضافية.

## الأسئلة الشائعة

### كيف يمكنني الحصول على مفتاح API لخرائط Google؟

يمكنك الحصول على مفتاح API لخرائط Google من [Google Cloud Platform](https://cloud.google.com/maps-platform/). ستحتاج إلى تفعيل "Places API" لاستخدامه مع هذا البرنامج.

### هل البرنامج يعمل بدون إنترنت؟

البرنامج يحتاج إلى اتصال بالإنترنت للوصول إلى مصادر البيانات مثل خرائط Google ومنصات الحجز. ومع ذلك، يمكنك استخدام وظائف البحث والتحليل في قاعدة البيانات المحلية بدون اتصال.

### هل يمكنني تشغيل البرنامج على نظام Linux أو macOS؟

نعم، البرنامج يعمل على جميع أنظمة التشغيل التي تدعم Python. على Linux أو macOS، استخدم الأمر التالي بدلاً من run.bat:
```
python main.py
```

### ما هي متطلبات الذاكرة للبرنامج؟

يعتمد على حجم البيانات التي تعمل عليها. للاستخدام العادي، نوصي بـ 4GB من ذاكرة الوصول العشوائي على الأقل. لتحليل كميات كبيرة من البيانات، قد تحتاج إلى 8GB أو أكثر.

1. قم بعمل fork للمشروع.
2. قم بإنشاء فرع جديد للميزة التي ترغب في إضافتها.
3. قم بتنفيذ التغييرات والتأكد من أنها تعمل بشكل صحيح.
4. قم بإرسال طلب سحب (pull request) مع وصف مفصل للتغييرات.
